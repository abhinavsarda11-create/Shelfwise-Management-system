# Shelfwise v2 - Retail Inventory and Order Management

React 18, Framer Motion, Recharts, Leaflet | Node.js and Express | MongoDB Atlas (Mongoose)

## What is new in v2
- Real multi-user accounts: register, sign in, change password. Every account has a private workspace.
- Sample data per account: 100 real-brand products, 12 suppliers, 160 customers and 520 orders across 45 Indian cities.
- Real locations: customers, suppliers and orders carry city, state, PIN prefix and coordinates. Customer forms can detect the nearest city from the browser location.
- Dashboard with 30-day trends, category mix, top products, state revenue and restocking list.
- Analytics page with a sales map, monthly revenue, payment mix, weekday pattern and top customers.
- Orders with payment method, discount and printable invoice. CSV export for products, customers, suppliers and orders.
- Sorting, filtering, pagination, and a stock log that records every movement.

## Where the data comes from and where it is inserted
- Cities, states, coordinates and PIN prefixes: backend/data/cities.js (real Indian locations).
- Products and brands: backend/data/catalogue.js (real brands with approximate retail prices in INR).
- Customers, orders and stock history: generated by backend/seed.js with realistic patterns (weekend peaks, popular items sell more, most orders near the store city, a few cancellations, some low and out-of-stock items). Names, phone numbers and street addresses are generated, not real people.
- Insertion: backend/seed.js writes directly into MongoDB collections (suppliers, products, customers, orders, stocklogs, counters), tagged with the account id. It runs when an account is created with sample data ticked, or from Settings, Load sample data.
- New records you add yourself go through the API routes in backend/routes, which validate and then save to MongoDB.

## Run locally
1. Copy backend/.env.example to backend/.env and set MONGODB_URI and JWT_SECRET.
2. Terminal 1: cd backend, npm install, npm start
3. Terminal 2: cd frontend, npm install, npm run dev
4. Open http://localhost:5173 and create an account.

## Environment variables
MONGODB_URI (required), JWT_SECRET (required), ALLOW_SIGNUP (optional, set to false to close registration)

## Deploy on Vercel
1. Push this folder to GitHub.
2. MongoDB Atlas: Network Access, add 0.0.0.0/0. Create a database user with a letters-and-numbers password.
3. Vercel: Add New, Project, import the repository, preset Other. Add MONGODB_URI and JWT_SECRET. Deploy.
4. Open the site and create your account.
